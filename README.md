# ai-design-tells

Скилл для Claude Code и инструкция для Codex: как не делать интерфейсы, по которым сразу видно, что их собрал ИИ,
и не забыть то, что агенты обычно забывают.

Кодинг-агенты тянутся к одним и тем же решениям по умолчанию: градиенты, фиолетовый на чёрном, «жидкое стекло»,
эмодзи вместо иконок, три карточки в ряд, длинные тире в каждом предложении, «это не X, это Y». По отдельности это <!-- design-tells: ignore -->
нормально, вместе страница выглядит сгенерированной и вызывает меньше доверия. Обратная сторона в том, что агенты пропускают
базовое: реальные скриншоты продукта, состояния загрузки, пустые и ошибочные состояния, условия использования и
политику конфиденциальности.

## Что внутри

| Файл | Для чего |
|---|---|
| `skills/ai-design-tells/SKILL.md` | Сам скилл: что не делать (визуал и тексты), чем заменить, что не забыть. Для Claude Code. |
| `skills/ai-design-tells/scripts/check_design_tells.py` | Проверка файлов HTML/CSS/JS/TS/JSX/TSX/Vue/Svelte/Markdown: находит кандидатов с файлом и строкой. Ничего не правит. |
| `AGENTS.md` | Те же правила для Codex и других агентов, читающих `AGENTS.md`. |

## Установка

**Claude Code.** Скопировать папку скилла:

```bash
# для всех проектов
cp -r skills/ai-design-tells ~/.claude/skills/
# или только для одного проекта
cp -r skills/ai-design-tells <проект>/.claude/skills/
```

Скилл подхватывается автоматически, когда задача про интерфейс; можно вызвать и явно: `/ai-design-tells`.

**Codex.** Скопировать папку `skills/ai-design-tells` в проект и добавить четыре пункта из `AGENTS.md` в
`AGENTS.md` проекта (или в `~/.codex/AGENTS.md`).

## Проверка

```bash
python skills/ai-design-tells/scripts/check_design_tells.py путь/к/проекту
python skills/ai-design-tells/scripts/check_design_tells.py page.html --strict   # код возврата 1, если что-то нашлось
python skills/ai-design-tells/scripts/check_design_tells.py src --json           # для CI и агентов
```

Это эвристика: она показывает места, которые стоит посмотреть. Строку, где паттерн нужен осознанно (например, цитата), можно пометить комментарием `design-tells: ignore`. Решает человек или агент: исправить, оставить
осознанно (с причиной) или «не применимо». Например, ряд плиток с цифрами уместен в операционной админке и
неуместен на лендинге.

## Пример

Первый прогон: админка сервиса поддержки (2155 строк HTML/CSS/JS): 98 длинных тире в текстах, 7 цветных полосок
слева, 13 сильных скруглений, 4 правила с заглавными подписями, одна конструкция «не X, а Y». Градиентов, стекла, <!-- design-tells: ignore -->
фиолетового, эмодзи и шрифтов по умолчанию нет.
